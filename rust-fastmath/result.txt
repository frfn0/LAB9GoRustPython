2. Импорт и вызов из Python
----------------------------
Модуль fastmath собран на Rust и импортируется в Python
   fastmath: C:\Python\lib\site-packages\fastmath\__init__.py
   экспортированные функции: fastmath, isqrt, mean, sum_squares

fastmath.sum_squares([1, 2, 3, 4, 5]) = 55
fastmath.mean([1, 2, 3, 4])          = 2.5
fastmath.isqrt(17)                    = 4

3. Ошибки Rust становятся исключениями Python
---------------------------------------------
fastmath.mean([]) -> ValueError: mean(): список чисел не должен быть пустым
fastmath.isqrt(-1) -> ValueError: isqrt(): число не должно быть отрицательным, получено -1

Как устроена связка Rust и Python
---------------------------------
Rust                                        Python
----                                        ------
#[pyfunction] sum_squares(Vec<i64>)  --->    fastmath.sum_squares([1, 2, 3])
m.add_function(wrap_pyfunction!(..))          функция в модуле fastmath
PyValueError::new_err(...)            --->    ValueError с текстом на русском
#[pymodule] fn fastmath(m)            --->    import fastmath
crate-type = ["cdylib"] + maturin    --->    fastmath.cp310-win_amd64.pyd

Ключевой момент: Vec<i64> на границе FFI превращается в обычный Python-список,
i64 - в int, а ошибки Rust автоматически конвертируются в исключения Python,
поэтому вызовы неотличимы от обычных функций.
