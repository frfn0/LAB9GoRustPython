Задание 2. HTTP-сервер с горутиной фоновой обработки: фактический вывод
=======================================================================

Дата проверки: 2026-10-06
Запуск: go run ./go-service   (порт 8080, только стандартная библиотека)

1. Основной эндпоинт POST /process
----------------------------------
> curl -X POST http://127.0.0.1:8080/process \
       -H "Content-Type: application/json" \
       -d '{"numbers":[1,2,3,4,5]}'
{"status":"accepted","job_id":1,"accepted":5}
HTTP 202

Клиент сразу получает ответ, не дожидаясь вычисления: sum квадратов
1..5 = 55 считается в фоновой горутине.

2. Обработка ошибок
------------------
> curl -X POST http://127.0.0.1:8080/process \
       -H "Content-Type: application/json" \
       -d '{"numbers":[]}'
поле numbers не должно быть пустым
HTTP 422

3. Пять запросов подряд - пять фоновых горутин
----------------------------------------------
POST /process -> HTTP 202 {"status":"accepted","job_id":1,"accepted":3}
POST /process -> HTTP 202 {"status":"accepted","job_id":2,"accepted":3}
POST /process -> HTTP 202 {"status":"accepted","job_id":3,"accepted":3}
POST /process -> HTTP 202 {"status":"accepted","job_id":4,"accepted":3}
POST /process -> HTTP 202 {"status":"accepted","job_id":5,"accepted":3}

4. Состояние фоновой обработки GET /stats
-----------------------------------------
> curl http://127.0.0.1:8080/stats
{"processed_jobs":5,"last_job_id":5,"last_sum":110}

6. Graceful shutdown по Ctrl+C
------------------------------
Событие остановки отправлено процессу, код возврата: 0

2026/10/06 18:12:43 получен сигнал завершения, останавливаю сервер
2026/10/06 18:12:43 все фоновые горутины завершены, сервис остановлен

Сервис дождался завершения всех фоновых горутин (sync.WaitGroup) и только
после этого вышел из main, поэтому ни одна задача не потеряна.
