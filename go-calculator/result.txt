Задание 4. Передача данных из Python в Go через JSON: фактический вывод
=======================================================================

Дата проверки: 2026-10-06
Запуск: python python/demo_task4.py
Модуль на Go: go-calculator (только стандартная библиотека encoding/json)

1. Пример из методички
----------------------
Пример из методички: [1, 2, 3, 4, 5]
  ответ Go: {'count': 5, 'sum_of_squares': 55, 'sum': 15}

2. Обмен структурой в обе стороны
---------------------------------
Структура с меткой, чтобы видеть обмен полями туда и обратно:
  ответ Go: {'label': 'отчёт за неделю', 'count': 3, 'sum_of_squares': 1400, 'sum': 60}
  метка вернулась из Go без изменений: 'отчёт за неделю'

Кириллица в поле label корректно проходит через stdin и обратно через stdout,
потому что Python передаёт subprocess-коду text=True, encoding="utf-8".

3. Отрицательные числа
----------------------
Отрицательные числа:
  ответ Go: {'label': 'смешанные', 'count': 2, 'sum_of_squares': 41, 'sum': 1}

4. Обработка ошибок
-------------------
Обработка ошибки: пустой массив чисел
  поймано ожидаемое исключение: калькулятор завершился с кодом 1:
  ошибка: поле "numbers" должно быть непустым массивом чисел

Go пишет ошибку в stderr и возвращает код 1, Python превращает это
в CalculatorError. В stdout при ошибке ничего не попадает.
